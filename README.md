## 💻 Run Locally

Clone the repository:

```bash
git clone https://github.com/TusarKhatri/Tusar-Portfolio.git
```

Move into the project:

```bash
cd Tusar-Portfolio
```

Then open `index.html` with VS Code Live Server.

No Node.js installation is required for the portfolio itself.
